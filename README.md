- **Live projects:** SevaRecover, Event Management System, Campus Voting dApp, ChainMatrix
- **Links:** [GitHub](https://github.com/LakshmiHasini) · [LinkedIn](https://www.linkedin.com/in/batchu-lakshmi-hasini-09b092318/)

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Hosting

GitHub Pages publishes the root of the `main` branch. Keep the `CNAME` file with
`lakshmihasini.in` in the publishing source to preserve the custom domain.
